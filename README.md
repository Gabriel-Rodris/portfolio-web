# Portfólio de Gabriel Rodrigues

[Ver site](https://gabriel-rodris.github.io/portfolio-web/)

Portfólio estático em português, feito com HTML e CSS. A publicação no GitHub Pages usa a raiz da branch `main`. Para rodar localmente, abra `index.html` no navegador.

- `index.html` contém projetos, trajetória e contato.
- `style.css` contém a tipografia, os estilos e as regras responsivas.
- `assets/` contém o retrato do portfólio anterior e uma captura pública de Runecast.
