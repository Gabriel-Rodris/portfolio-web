# Portfólio de Gabriel Rodrigues

[Ver site](https://gabriel-rodris.github.io/portfolio-web/)

Portfólio estático em português, feito com HTML, CSS e JavaScript. A publicação no GitHub Pages usa a raiz da branch `main`. Para rodar localmente, abra `index.html` no navegador.

- `index.html` contém projetos, trajetória e contato.
- `style.css` contém o layout responsivo e `grafite.css` define a paleta Grafite.
- `motion.js` aplica animações com GSAP e respeita a preferência por movimento reduzido.
- `assets/` contém o retrato, as imagens dos projetos e a fonte.
